# Privacy Model

Версия 1 строится как local-first продукт.

## Что хранится локально

Основное хранилище:

- IndexedDB

В IndexedDB лежат:

- локальные профили
- все ответы
- вычисленные шкалы
- производные показатели
- текстовые интерпретации
- metadata для прогресса прохождения

Дополнительное простое хранилище:

- `localStorage`

В `localStorage` используется только:

- `self-understanding-active-profile-id`
- тема интерфейса через `next-themes`

## Что не отправляется на сервер

В версии 1 нет:

- обязательной авторизации
- серверной БД профилей
- API для хранения результатов
- скрытой отправки ответов на удалённый endpoint
- AI-анализа внутри продукта

## Когда данные покидают устройство

Только в момент, когда пользователь сам инициирует это через интерфейс:

- экспорт JSON
- экспорт Markdown/TXT
- экспорт короткой сводки
- export comparison-package

То есть продукт ничего не синхронизирует автоматически.

## Импорт

При импорте JSON:

- файл читается локально в браузере
- валидируется через schema
- записывается в IndexedDB
- при конфликте ID создаётся локальная копия, чтобы не перезаписывать профиль молча

## Ограничения privacy-модели

- Если пользователь сам передаст экспорт третьей стороне, продукт больше не контролирует этот файл.
- В comparison-package.md и полном Markdown-экспорте может содержаться личная текстовая заметка из `about`.
- Поэтому экспорт следует рассматривать как чувствительный пользовательский файл.
