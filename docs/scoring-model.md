# Scoring Model

Документ описывает, как считаются шкалы и производные показатели в версии 1.

## Общие принципы

- Все ответы хранятся по шкале 1-5.
- Для всех основных шкал считается `rawMean`.
- Для интерфейса и экспорта дополнительно считается `normalized = ((rawMean - 1) / 4) * 100`.
- Уровни `low / medium / high` используются только как описательные диапазоны:
  - `low`: `< 35`
  - `medium`: `35..65`
  - `high`: `> 65`
- Эти диапазоны не являются нормативными и не должны трактоваться как клинические пороги.

## 1. Big Five

### Базовая логика

- Каждая шкала строится как среднее по 10 пунктам.
- Для пунктов противоположной полярности используется обратное кодирование: `6 - answer`.

### Пользовательские шкалы в продукте

- `openness-to-new`
- `conscientiousness`
- `extraversion`
- `agreeableness`
- `emotional-sensitivity`

### Методическая оговорка

- Для `openness-to-new` исходной научной подписью остаётся `Intellect / Imagination (Factor V)`.
- Для `emotional-sensitivity` исходной опорой остаётся фактор IV IPIP (`Emotional Stability`), но пользовательский display ориентирован в сторону neuroticism-like reading. Поэтому в данных сохранён `sourceScale`, а итоговая шкала для интерфейса уже направлена в сторону чувствительности.

### Производный показатель

- `big-five-trait-spread`
  - Формула: `max(normalized traits) - min(normalized traits)`
  - Назначение: показать, насколько профиль ровный или контрастный по пяти большим чертам
  - Это не норма и не «хорошо/плохо»

## 2. IPIP-IPC

### Октанты

Считаются восемь октантов по официальному scoring key:

- `PA` Assured-Dominant
- `BC` Arrogant-Calculating
- `DE` Cold-Hearted
- `FG` Aloof-Introverted
- `HI` Unassured-Submissive
- `JK` Unassuming-Ingenuous
- `LM` Warm-Agreeable
- `NO` Gregarious-Extraverted

Каждый октант строится как среднее по 4 пунктам.

### Центрирование

Для осей IPC сначала считается центрированное значение каждого октанта:

- `octantCentered = octantMean - 3`

Это позволяет интерпретировать нейтральную середину шкалы как точку около нуля.

### Сводные оси

Проекция выполнена по стандартной геометрии circumplex из статьи Markey & Markey (2009), где октанты расположены через 45 градусов.

#### Доминирование / подстройка

Формула:

`dominance = (PA + 0.707*NO + 0.707*BC - HI - 0.707*JK - 0.707*FG) / 2.414`

Где используются уже центрированные октантовые средние.

#### Теплота / дистанция

Формула:

`warmth = (LM + 0.707*NO + 0.707*JK - DE - 0.707*BC - 0.707*FG) / 2.414`

### Нормализация осей

- Сырые значения осей лежат примерно в диапазоне `-2 .. 2`
- Для визуализации они переводятся в `0..100`:

`normalizedAxis = ((rawAxis - (-2)) / 4) * 100`

### Важная оговорка

- Это описательная геометрическая проекция, а не «процент доминирования».
- Высокие или низкие значения осей не оцениваются как хорошие или плохие.

## 3. Конфликтный профиль

### Статус

- Блок является внутренним прикладным модулем v1.
- Он не претендует на психометрическую валидность.
- Его scoring сделан намеренно прозрачным и простым.

### Базовые шкалы

- `direct-confrontation`
- `avoidance`
- `defensiveness`
- `silent-withdrawal`
- `tension-accumulation`
- `harshness`
- `dialogue-readiness`
- `repair-capacity`

Каждая шкала считается как среднее по связанным пунктам блока.

### Производные показатели

#### Engagement vs withdrawal

- Формула:
  - `engagementBase = mean(direct-confrontation, dialogue-readiness)`
  - `withdrawalBase = mean(avoidance, silent-withdrawal, tension-accumulation)`
  - `engagement-vs-withdrawal = engagementBase - withdrawalBase`
- Нормализация для графиков:
  - диапазон приводится из `-4..4` к `0..100`
- Чем выше показатель, тем вероятнее, что человек остаётся в контакте с темой, а не уходит от неё.

#### Reactivity level

- Формула:
  - `mean(defensiveness, harshness, tension-accumulation)`
- Чем выше показатель, тем заметнее защитность, резкость и «остаточное» напряжение.

#### Repair potential

- Формула:
  - `mean(dialogue-readiness, repair-capacity, 6 - tension-accumulation)`
- Чем выше показатель, тем проще возвращаться к разговору после напряжения.

## Текстовые интерпретации

- Все тексты формируются детерминированно по правилам bands и комбинациям шкал.
- Внутри продукта не используется LLM, AI inference или автоматический matchmaking.
- Формулировки специально написаны как склонности, паттерны и особенности взаимодействия.
