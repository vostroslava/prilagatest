# Test Sources

Документ фиксирует, какие методики использованы в версии 1, откуда взяты вопросы, какой у них статус использования и как в проекте обработаны переводы.

## 1. Big Five

- Основа: 50-item IPIP Big-Five Factor Markers
- Официальный источник: <https://ipip.ori.org/new_ipip-50-item-scale.htm>
- Статус использования: IPIP публикует эти пункты как public-domain item pool. См.:
  - <https://ipip.ori.org/>
  - <https://ipip.ori.org/newPermission.htm>
- Официальная русская версия: <https://ipip.ori.org/Russian50-itemBigFiveFactorMarkers.htm>
- Страница с item codes, использованная для сохранения исходных идентификаторов: <https://ipip.ori.org/German50-itemBigFiveFactorMarkers.htm>

### Что сохранено в проекте

- `itemId`: официальный IPIP item code
- `originalText`: английская формулировка
- `russianText`: русская формулировка на базе официальной IPIP-страницы
- `answer`: локальный ответ по шкале 1-5
- `reverseKeyed`: рабочий признак обратного кодирования для итоговой пользовательской шкалы
- `scaleKey`: пользовательская шкала внутри продукта
- `scientificScale`: научная подпись фактора
- `source`: ссылка на инструмент и статус перевода

### Что оригинально, что переведено, что адаптировано

- Английские вопросы: оригинальные формулировки IPIP.
- Русские вопросы: взяты из официальной русской страницы IPIP.
- Для нескольких строк исправлены только очевидные типографические мелочи без изменения смысла.

### Важная методическая оговорка

- Фактор V в IPIP-странице подписан как `Intellect / Imagination`. В интерфейсе продукта он показан как `Открытость новому`, но в данных сохраняется научная подпись исходного фактора.
- Фактор IV на странице IPIP связан с `Emotional Stability`. В интерфейсе продукта показана более мягкая пользовательская шкала `Эмоциональная чувствительность`, то есть та же ось, отображённая в направлении neuroticism-style display. Это прямо отражено в `sourceScale`.

## 2. Межличностный стиль

- Основа: IPIP-IPC short form
- Официальный survey page: <https://ipip.ori.org/newIPIP-IPCSurvey.htm>
- Официальный scoring key: <https://ipip.ori.org/newIPIP-IPCScoringKey.htm>
- Статус использования: вопросы идут из открытого IPIP item pool и могут использоваться в локальном продукте без отдельной лицензии; см. общие IPIP permission pages выше.
- Научная ссылка на краткую форму: Markey, P. M., & Markey, C. N. (2009). *A brief assessment of the interpersonal circumplex: The IPIP-IPC*. Assessment, 16, 352-361.
- Рабочий PDF mirror, использованный для фиксации геометрии октантов и осей: <https://www.ipip.uksw.edu.pl/file/60>

### Что сохранено в проекте

- `itemId`: исходный номер пункта из survey page
- `originalText`: английская формулировка
- `russianText`: перевод, адаптированный внутри проекта
- `answer`: локальный ответ по шкале 1-5
- `scaleKey`: один из восьми октантов IPC
- `scientificScale`: английская научная подпись октанта

### Что оригинально, что переведено, что адаптировано

- Английские вопросы: оригинальные формулировки IPIP-IPC.
- Русские вопросы: не брались из официальной валидированной русской публикации; это аккуратный продуктовый перевод с английского.
- Поэтому в документации и в данных эти формулировки помечены как `translationStatus: adapted`.

## 3. Конфликтный профиль

- Основа: внутренний прикладной модуль продукта
- Статус: невалидированный исследовательский блок версии 1
- Источник в проекте: `internal://conflict-profile-v1`

### Принцип использования

- Блок не выдаётся за академический, клинический или диагностический тест.
- Блок нужен только для прозрачного описания повторяющихся конфликтных паттернов в локальном профиле.
- Все формулировки созданы внутри проекта на русском языке и помечены как `translationStatus: internal`.

## Что не использовано

- Не использовались закрытые тесты с лицензированием.
- Не использовались клинические, диагностические или медицинские шкалы.
- Не использовались псевдонаучные совместимости, матчинги и автоматические verdict-like механики.
